# macOS Cheatsheet

## Aerospace Parity

The Omarchy keymap mirrors the useful intent from `stow/aerospace/.config/aerospace/aerospace.toml` without copying macOS-only syntax.

| macOS / Aerospace intent | Omarchy equivalent |
|---|---|
| `Ctrl+1..7` workspace switching | `Ctrl+1..9` workspace switching |
| `Ctrl+Shift+1..7` move window and follow | `Ctrl+Shift+1..9` move window and follow |
| `Alt+B` browser launcher | `Alt+B` Vivaldi |
| `Alt+Shift+B` alternate browser | `Alt+Shift+B` Firefox |
| `Alt+G` ChatGPT launcher | `Alt+G` ChatGPT desktop app |
| `Alt+E` email launcher | `Alt+E` Thunderbird |
| `Alt+Shift+Return` alternate terminal | `Alt+Shift+Return` Alacritty |

## Notes

Omarchy keeps physical Alt and Super keys unchanged. The Linux Super key is used like macOS Command where it is safe, while terminal behavior stays app-specific to avoid breaking shell, Tmux, and Neovim workflows.
